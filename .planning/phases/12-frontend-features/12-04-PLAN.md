1. Update **api.ts** - Add rating hooks:
   - `useRateJoke()` - useMutation calling jokesApi.rate
     - On success: invalidate ['jokes', jokeId, 'rating'] and ['jokes', 'search'] queries
   - `useMyRating(jokeId)` - useQuery calling jokesApi.getMyRating
     - queryKey: ['jokes', jokeId, 'rating']
     - enabled: only when user is authenticated (check useAuth)

2. Create **hooks.ts** - Convenience hook:
   - `useJokeRating(jokeId)` - Combines useMyRating query and useRateJoke mutation
     - Returns: { rating, jokeScore, rate, isRating, canRate }
     - canRate: true if user is authenticated
  </action>
