**Collections API (from lib/api.ts):**
- collectionsApi.list() → PaginatedResponse<Collection>
- collectionsApi.create(name) → Collection
- collectionsApi.update(id, name) → Collection
- collectionsApi.delete(id) - Note: cannot delete default "Favorites"
- collectionsApi.getJokes(collectionId) → PaginatedResponse<SavedJoke>

**Collection type:**
{ id, name, is_default, joke_count, created_at }

**PROTECTED ROUTE:** This page requires authentication.

1. **api.ts** - Create TanStack Query hooks:
   - `useCollections()` - useQuery with queryKey ['collections'], calls collectionsApi.list
   - `useCollectionJokes(collectionId)` - useQuery with queryKey ['collections', id, 'jokes']
   - `useCreateCollection()` - useMutation, invalidates ['collections'] on success
   - `useUpdateCollection()` - useMutation, invalidates ['collections'] on success
   - `useDeleteCollection()` - useMutation, invalidates ['collections'] on success
   - `collectionKeys` - Query key factory

2. **index.ts** - Export all hooks

Configure queries with appropriate staleTime (5 min is fine for collections).
